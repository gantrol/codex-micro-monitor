# Codex Micro Monitor 1.0.4

Release candidate; not yet published. Desktop and plugin version: `1.0.4`; Windows file/Store version: `1.0.4.0`.

## Changes

- Show the account Credits balance in the quota dial when a displayed plan window is exhausted, with precise localized formatting and safe unavailable or unlimited states.
- Isolate release restores by the pinned control-package hashes so an existing machine-wide NuGet cache cannot substitute different contents under the same package version.

## Distribution

The candidate includes desktop and plugin ZIPs, a compact Windows x64 ZIP, exact `1.0.2` control packages and SHA-256 checksums. ZIP builds require .NET 10 Desktop Runtime x64. A Store candidate uses its own self-contained MSIX build; preparing it does not submit it to Microsoft.

Automated tests and compilation do not establish compatibility with later Codex versions, physical hardware, a fresh plugin installation or the live Codex UI. The plugin directory submission remains pending.
