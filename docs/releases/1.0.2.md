# Codex Micro Monitor 1.0.2

Release candidate; not yet published. Desktop and plugin version: `1.0.2`; Windows file/Store version: `1.0.2.0`.

## Changes

- Detect failed Codex `task_complete` and `turn_aborted` rollout records instead of treating every closed turn as idle.
- Carry structured rollout error codes through task monitoring and preserve them across temporary file-access failures.
- Show `server_overloaded` failures as a localized **Model at capacity** state with a distinct coral status light.

## Distribution

The candidate includes desktop and plugin ZIPs, a compact Windows x64 ZIP, exact `1.0.1` control packages and SHA-256 checksums. ZIP builds require .NET 10 Desktop Runtime x64. A Store candidate uses its own self-contained MSIX build; preparing it does not submit it to Microsoft.

Automated tests and compilation do not establish compatibility with later Codex versions, physical hardware or a fresh plugin installation. The plugin directory submission remains pending.

## 简体中文

本版本为待发布候选版本，尚未公开发布。桌面应用与插件版本为 `1.0.2`，Windows 文件和商店版本为 `1.0.2.0`。

## 变更

- 识别失败的 Codex `task_complete` 和 `turn_aborted` rollout 记录，不再将所有已结束任务都视为空闲。
- 在任务监控链路中传递结构化错误码，并在 rollout 文件暂时无法访问时保留最近错误。
- 将 `server_overloaded` 显示为本地化的“模型容量已满”状态，并使用独立的珊瑚色状态灯。

自动化测试和编译不代表兼容后续 Codex 版本、真实硬件或全新插件安装；插件目录提交仍待处理。
