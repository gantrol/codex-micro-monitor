# Codex Micro Monitor 1.0.1

Release candidate; not yet published. Desktop and plugin version: `1.0.1`; Windows file/Store version: `1.0.1.0`.

## Changes

- Harden software session targeting so actions re-check the selected Codex chat, route and target version before writing.
- Use the native reasoning slider for MIND+ / MIND- and show explicit feedback when the slider reaches either boundary.
- Improve native composer controls, stale-target handling and software-control diagnostics, including target thread context.
- Support separate release-candidate output directories and pin the bundled `CodexControl` packages to `1.0.1`.

## Distribution

The candidate includes desktop and plugin ZIPs, a compact Windows x64 ZIP, exact `1.0.1` control packages and SHA-256 checksums. ZIP builds require .NET 10 Desktop Runtime x64. A Store candidate uses its own self-contained MSIX build; preparing it does not submit it to Microsoft.

Automated tests and compilation do not establish compatibility with later Codex versions, physical hardware or a fresh plugin installation. The plugin directory submission remains pending.

## 变更

- 强化软件会话定位，在写入前重新校验当前 Codex 聊天、路由和目标版本。

- 支持独立的发布候选输出目录，并将内置 `CodexControl` 包固定为 `1.0.1`。
