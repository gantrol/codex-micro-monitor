# Codex Micro Monitor 1.0.3

Release candidate; not yet published. Desktop and plugin version: `1.0.3`; Windows file/Store version: `1.0.3.0`.

## Changes

- Derive task lighting from the current desktop thread stream, including load state, current-turn identity and runtime state, instead of treating an unfinished rollout record as proof that a task is still running.
- Re-establish task observation after connection resets, owner changes, revision gaps or stale streams while preventing delayed snapshots and prior-turn errors or questions from overriding newer state.
- Detect replacement rollout files by Windows file identity and rebuild incremental parsing without losing accepted IPC answers during temporary read failures.
- Show persisted composer drafts with the existing task-key center dot and keep draft state independent from running, approval, question, error and unread lighting.
- Improve asynchronous-question Skip observation and add bounded model/Fast routing diagnostics without recording conversation content.

## Distribution

The candidate includes desktop and plugin ZIPs, a compact Windows x64 ZIP, exact `1.0.2` control packages and SHA-256 checksums. ZIP builds require .NET 10 Desktop Runtime x64. A Store candidate uses its own self-contained MSIX build; preparing it does not submit it to Microsoft.

Automated tests and compilation do not establish compatibility with later Codex versions, physical hardware, a fresh plugin installation or the live Codex UI. The plugin directory submission remains pending.

## 简体中文

本版本为待发布候选版本，尚未公开发布。桌面应用与插件版本为 `1.0.3`，Windows 文件和商店版本为 `1.0.3.0`。

## 变更

- 根据当前桌面会话流中的加载状态、当前回合身份和运行状态合成任务灯，不再把未结束的 rollout 记录直接当作仍在运行的证据。
- 在连接重置、owner 变化、修订缺口或流长时间无更新后重建任务观察，并阻止延迟快照、旧回合错误及旧问题覆盖新状态。
- 使用 Windows 文件身份识别同路径的 rollout 文件替换，重建增量解析；临时读取失败时仍保留已接受的 IPC 回答。
- 复用任务键中心圆点显示已持久化的输入草稿，并使草稿状态独立于运行、审批、问题、错误及未读灯态。
- 改进异步问题的 Skip 观察，并增加不记录对话内容的有界模型/Fast 路由诊断。
