# Codex Micro Monitor 1.0.6

Desktop and bundled plugin version: `1.0.6`; Windows file version: `1.0.6.0`.

## Changes

- Enable the Windows MIC and MIC1 keys through Codex's native dictation button. Click once to start and again to stop. The combined key now uses the same mouse, keyboard and accessibility activation as other action keys.
- Confirm dictation only after observing the opposite control on the same composer. Missing controls, changed targets and timeouts do not trigger automatic retries or message submission.
- Fix macOS dictation source so transcription text changes do not prevent stopping; require one unambiguous control and read back the same target.
- Pin `CodexControl` and `CodexControl.Windows` to `1.0.4` and update plugin capability reporting.

## Distribution and validation

Assets include the Windows desktop, compact and plugin ZIPs, source and SHA-256 checksums. Windows ZIPs require .NET 10 Desktop Runtime x64. The macOS source fix is included, but this release contains no new Mac binary. Microsoft Store and public plugin-directory submission remain separate.

The Release solution build completed with zero warnings and zero errors. Of 658 existing automated tests, 650 passed and 8 failed because their old assertions require dictation to remain unsupported. Test code was left unchanged under the project rules. No live UI acceptance was performed. The macOS changes have not been compiled or tested with Swift/Xcode.

## 简体中文

桌面应用与捆绑插件版本为 `1.0.6`，Windows 文件版本为 `1.0.6.0`。

## 变更

- Windows 的 MIC、MIC1 键接入 Codex 原生听写按钮，点击开始，再次点击停止。双宽键与其他动作键统一使用鼠标、键盘和无障碍激活。
- 只在同一输入框读回相反状态后确认听写切换成功；控件消失、目标改变或超时均不自动重试，也不发送消息。
- 修复 macOS 听写源码中转写文字变化导致停止失败的问题，并要求唯一控件与相同目标读回。
- `CodexControl` 和 `CodexControl.Windows` 固定为 `1.0.4`，同步更新插件能力报告。

## 分发与验证

附件包含 Windows 桌面包、精简包、插件包、源码及 SHA-256 校验值。Windows ZIP 需要 .NET 10 Desktop Runtime x64。本次包含 macOS 源码修复，没有新的 Mac 程序包；Microsoft Store 与公开插件目录另行提交。

Release 完整构建为 0 警告、0 错误。658 项现有自动化测试中，650 项通过、8 项失败；失败项仍断言听写功能不支持。按项目规则保留测试代码，未进行真实界面验收。macOS 修改尚未经 Swift/Xcode 编译和测试。
