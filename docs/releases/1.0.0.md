# Codex Micro Monitor 1.0.0

Release candidate; not yet published. Desktop and plugin version: `1.0.0`; Windows file/Store version: `1.0.0.0`.

## Changes

- Adopt GPL-3.0-only for project-owned code and the bundled plugin. Commercial use is permitted under the license's conditions.
- Document the modified Micro recreation and unresolved third-party visual licensing separately from the project's software license.
- Include the configurable keycaps, composer controls, compact settings and context-menu updates already present in the current source.
- Pin both shared control packages to `1.0.0`, with matching GPL license metadata and source.

## Distribution

The candidate includes desktop and plugin ZIPs, a compact Windows x64 ZIP, corresponding project/control source archives, exact control packages and SHA-256 checksums. ZIP builds require .NET 10 Desktop Runtime x64. A Store candidate uses its own self-contained MSIX build; preparing it does not submit it to Microsoft.

The driverless adaptation baseline remains Codex `26.930.3930.0`. Automated tests do not establish compatibility with later Codex versions, physical hardware or a fresh plugin installation. The plugin directory submission remains pending. Third-party graphics, marks and design rights are not cleared by this license change; see the [README notice](../../README.md#notice).
