- Codex Micro：功能、测试与维护总纲
  - MC-00 范围与基准
    - 维护目的：从功能分支找到需求、行为规则、测试用例、问题和验收证据，不依赖历史聊天恢复上下文。
    - 当前范围：Windows 免驱 Micro；其他客户端和硬件通道分别记录，不继承 Windows 测试结果。
    - 设计日期：2026-10-04；隔离测试已部分落地，本文仍是规划入口，不表示所有功能或测试已经完成。
    - 实现基准：每次执行测试时填写应用版本、控制组件版本、源码提交、未提交差异和实际 Codex 版本。
    - 当前详细设计：[可更换按钮测试用例重设计](keycap-test-design.zh-CN.md)。已有功能规则：[可更换按键与 Sketch](keycap-actions.zh-CN.md)。
    - 共用准则：[Micro 测试准则与分层](testing-strategy.zh-CN.md)；采用 AIY 的风险、分层与证据方法，测试保留在本仓现有项目。
    - 维护方式：MC 编号保持稳定；新增分支追加编号，不因调整树中顺序重编号。A／E／S／J／G 编号关联详细用例。
  - MC-01 连接与运行生命周期
    - MC-01.1 启动与发现
      - 应用首次启动、Codex 未启动、Codex 已运行、多窗口、重复启动。
      - 验收重点：找到正确目标；不创建重复控制实例；失败能定位原因。
    - MC-01.2 连接与恢复
      - 连接成功、超时、断开、手动重连、Codex 重启、控制协议不匹配。
      - 验收重点：连接状态准确；恢复连接不重放已经失败或过期的按钮输入。
    - MC-01.3 退出与取消
      - 隐藏窗口、关闭窗口、退出程序、正在执行时退出。
      - 验收重点：取消未完成任务，释放管道、观察器和计时器；不留下迟到操作。
    - 测试关联：G04、G06、G08；后续连接专项在本分支扩展。
  - MC-02 目标会话与任务监控
    - MC-02.1 当前目标身份
      - 已确认会话、已确认草稿、目标未知、正在导航分别处理。
      - 会话 A→B→A、草稿 D1→D2、模型选择器替换、多个窗口身份冲突。
      - 验收重点：相同标题、相同空 ID 或回到原会话，不会让旧输入重新生效。
    - MC-02.2 Agent 会话键
      - 会话列表来源、空槽位、切换会话、点击后激活、列表更新时的按键目标。
      - 验收重点：按键指向稳定会话身份，不根据显示位置或标题误开其他会话。
    - MC-02.3 监控页
      - 控制页／监控页切换、任务列表、运行与完成状态、共享发送键与旋钮。
      - 验收重点：状态刷新与页面切换不改变正在执行动作的目标。
    - MC-02.4 未读与待回答
      - 标记未读、读取确认、待回答、接受回答、跳过问题、迟到状态更新。
      - 验收重点：一个问题结束不清除另一个问题；旧快照不覆盖新状态。
    - 测试关联：目标矩阵 T1–T6、G01–G02；保留现有选择、问答和监控回归。
  - MC-03 键帽选择与动作绑定
    - MC-03.1 目录与图案
      - 全部 40 个键帽、单宽／双宽限制、搜索、实际图标绑定、未知键帽。
      - 验收重点：图案存在与功能已实现分别判断；不能把渲染成功算作动作可用。
    - MC-03.2 初次配置
      - MIC1／EMPT1 等占位键选择可用键帽后带入默认动作。
      - 验收重点：选择后可保存，重新打开仍是用户选定的动作。
    - MC-03.3 已有绑定
      - 默认动作、显式命令、旧 commandId、技能绑定、只更换图案。
      - 验收重点：已有动作保留；用户手选动作优先于后续图案选择。
    - MC-03.4 编辑会话
      - 异步加载技能、同名技能不同路径、筛选、语言切换、取消、Esc、关闭。
      - 验收重点：异步返回不覆盖用户选择；取消不写入配置。
    - MC-03.5 八个可保存位置
      - ACT06、ACT07、ACT08、ACT09、ACT10、ACT11、ACT10_ACT11、ACT12。
      - 验收重点：各位置独立保存；隐藏的合并／拆分位置不接收输入。
    - MC-03.6 语音区域拆分
      - 合并、拆分、两枚独立键、合并键原有绑定、重复切换布局。
      - 验收重点：三份绑定保留；拆分键使用普通动作语义。
    - 测试关联：E01–E11、J01–J04。规则维护在“可更换按键与 Sketch”，具体用例维护在测试设计。
  - MC-04 命令与技能执行
    - MC-04.1 会话操作
      - A01 新建会话：请求、导航确认、打开失败。
      - A02 分叉会话：创建结果、打开新会话、创建成功但打开失败。
      - A05 Review：当前验收“打开”；再次关闭属于尚未实现的往返能力。
    - MC-04.2 模型与模式
      - A03 Fast：已有会话 IPC、确认草稿原生菜单、连续点击和状态读回。
      - A04 Plan：已有会话／草稿往返，文本、附件和其他设置保留。
      - A08 推理强度增加：上调一档、上限、后台、未知目标。
      - A09 推理强度减少：下调一档、下限、后台、未知目标。
    - MC-04.3 审批与运行控制
      - A06 批准：唯一待审批项、类型、request ID、确认回执。
      - A07 拒绝：与批准成对验证，决定不可写反。
      - A10 停止：当前 turn、过期 turn、目标切换、重复按下。
    - MC-04.4 输入与内容
      - A11 发送：后台首按激活，前台再按发送；实际绑定决定行为。
      - A12 Sketch：添加菜单、唯一绘图项、编辑器已开、结果确认。
      - A16 技能：名称与路径、mention 插入、草稿保留、无自动发送。
    - MC-04.5 页面导航
      - A13 侧栏开关：状态往返与控件不可用。
      - A14 后退：历史边界、目标变化与结果不确定。
      - A15 前进：方向正确、历史边界与结果不确定。
    - MC-04.6 未接入与未分配
      - 语音 MIC／MIC1；附件 PAINT／UPL；终端、复制、归档、浏览器、置顶。
      - Git／PR／分支／合并；反馈、外链、环境动作、设置、侧聊、任务、文件夹、技能选择器、预置文本。
      - EMPT1–EMPT5 空白占位。
      - 验收重点：不支持的动作不可派发或保存为可用动作；对应图标仍可绑定受支持命令。
      - 状态记录：拒绝测试通过不改变 NotImplemented／Unassigned 的功能状态。
    - 测试关联：A01–A16；每个命令验证效果，每个位置验证实际入口，再按约束补组合。15 × 8 只在适用的低层验证路由映射，不要求 120 条完整旅程。每例判断目标、参数、次数、结果及禁止副作用。
  - MC-05 旋钮与摇杆
    - MC-05.1 旋钮输入
      - 点击、滚轮、拖动、高分辨率滚轮积累、方向反转、快速反向、过期输入。
    - MC-05.2 旋钮模式
      - 推理强度、对话滚动、输入框控件导航、快捷模型 A／B。
      - 验收重点：模式切换清除旧意图；边界停止；点击与转动不重复执行。
    - MC-05.3 摇杆
      - 上下左右绑定、角度与死区、保持方向、回中、快速变向。
      - 验收重点：保持方向不重复派发，回中后可再次触发；Plan 草稿路径与普通按钮一致。
    - MC-05.4 模型与推理同步
      - 模型目录更新、支持档位、快捷模型配置、目标切换后的状态恢复。
    - 测试关联：复用现有手势、积累器、方向和模型测试；执行结果共用 MC-04 的合同，目标变化共用 G01–G06。
  - MC-06 配置保存与恢复
    - MC-06.1 格式与往返
      - 展开 TOML、槽位 inline table、完整布局 inline table、默认配置、旧字段。
      - 注释、Unicode、路径转义、CRLF／LF、其他应用设置保留。
    - MC-06.2 动作与图标一致性
      - Codex 配置与 Micro 图标配置、内存状态、重新加载后的实际绑定。
      - 验收重点：普通保存失败不能偷偷改变动作；部分保存需明确状态。
    - MC-06.3 冲突与故障
      - 写入失败、替换失败、图标失败、外部编辑、多个编辑器、与拆分开关并发。
    - MC-06.4 重置与重启
      - 重置布局／图标、取消重置、服务重建、应用重启、损坏配置恢复。
    - MC-06.5 等待与关闭
      - 保存进行中继续操作或关闭、异步回调晚到、失败后重试。
    - 测试关联：S01–S10、J05；每例使用独立临时目录，重新创建读取对象核对持久结果。
  - MC-07 反馈、提示与呈现
    - MC-07.1 操作结果
      - 已确认、暂不可执行、结果未知、失败、未分配分别表达。
      - 验收重点：请求发出不等于效果确认；未知结果不自动重发。
    - MC-07.2 状态灯
      - 连接灯、活动灯、任务灯、绿色／黄色／红色复位、旧计时器晚到。
    - MC-07.3 按键名称与图案
      - 实际动作名称、图标覆盖、Fast 状态、禁用原因、无障碍名称与状态。
    - MC-07.4 配额与模型显示
      - 配额已知／未知／读取失败、数据刷新、模型与推理档位变化。
      - 验收重点：显示失败不伪造剩余额度；旧目标数据不更新当前目标。
    - MC-07.5 诊断
      - 记录动作、结果分类与原因；必要字段完整；本机证据与公开设计分开。
    - 测试关联：G07–G09；现有配额与灯效测试独立维护，不用截图通过替代动作验收。
  - MC-08 窗口、输入与可访问性
    - MC-08.1 窗口行为
      - 不抢焦点、置顶、隐藏、托盘恢复、移动、缩放、窗口位置保存。
    - MC-08.2 鼠标与键盘
      - 可见操作入口、焦点提示、Tab 导航、Enter／Space、菜单关闭后焦点恢复。
    - MC-08.3 显示适配
      - 多屏 DPI、文字放大、高对比度、减少动态效果、窗口尺寸边界。
    - MC-08.4 语言
      - 英文、中文、语言切换后的标签／状态同步；原生识别名称独立验证。
    - MC-08.5 页面与浮层
      - 控制页、监控页、设置、键帽编辑器；关闭与返回不丢配置意图。
    - 测试关联：E07、E08、E10、G09；离屏检查和真实系统验收分别记录。
  - MC-09 插件、控制组件与分发
    - MC-09.1 插件入口
      - MCP 参数、指定会话打开、重复启动、已有实例唤起、无效目标拒绝。
    - MC-09.2 控制组件边界
      - 软件 IPC、App Server、原生 UI 适配器、包版本和行为合同。
      - 验收重点：Micro 引用实际发布包；不能仅凭另一个仓库源码通过就声称当前包已验证。
    - MC-09.3 打包与安装
      - 当前支持的独立包／商店包、必要文件、启动入口、升级后配置保留。
    - MC-09.4 平台范围
      - Windows 当前实现；其他平台按已有专题独立规划和验收，不推定能力相同。
    - 测试关联：插件与发布专项尚需单列具体用例；本轮只建立维护入口，不声称已经覆盖。
  - MC-10 测试编排与验收证据
    - 规划顺序：用户旅程→损失与不变量→最低合适验证层→补足边界→执行证据。功能、层次、优先级和执行时机分别记录。
    - MC-10.1 L0 场景化单元：数据与规则
      - 目录、绑定优先级、纯解析、命令参数、目标代次、队列和反馈状态机。
      - 方法：等价类、边界值、决策表、状态转换、不变量；使用最小合成输入和可控时间。
      - 证据边界：不证明真实控件接入、文件已持久保存或跨进程接线。
    - MC-10.2 L1 WPF 组件：真实控件与绑定
      - 真实免驱 profile、编辑器选择、控件事件、异步返回、状态展示、编辑入口及可访问属性。
      - 保留被测组件链；进程、配置或时间替身逐项登记。E01–E11、G07–G09 在本层有入口证据。
      - 证据边界：离屏组件不证明真实桌面焦点、物理键盘、DPI 布局或原生 UIA。
    - MC-10.3 L2 协议与外部适配：隔离集成
      - 真实消息解析与适配器，合成接收端独立记录参数、目标、回执和效果。
      - 覆盖畸形响应、状态未变、超时、断开；A01–A16 按实际通道分配，不假设全部走同一协议。
      - 证据边界：回调 fake 不证明管道序列化，合成原生控件不证明真实 Codex 兼容。
    - MC-10.8 L3 存储与服务：保存与恢复
      - S01–S10 使用真实临时 TOML／图标文件及实际读写服务，验证合法性、冲突、回滚、重载与清理。
      - 注入写入／替换故障，用独立预期核对准确内容和无关配置；不读取用户工作配置。
      - 证据边界：重建服务对象不等于进程重启，两文件可捕获失败恢复不等于崩溃原子性。
    - MC-10.9 L4 进程与系统边界：宿主接线
      - 主窗口实际入口→控制组件→系统激活／URI／外部连接；取消、重连、关闭和资源释放。
      - A08–A09、J03、G01–G06 验证宿主与身份保护；真实子进程启动／崩溃／恢复另列证据。
      - 证据边界：直调 Transport 不能证明窗口接入，同进程模拟端不能证明跨进程生命周期。
    - MC-10.4 L5 端到端：代表用户旅程
      - J01 占位键改为新建→保存→重载→执行。
      - J02 保留批准图案、绑定推理加→执行时无审批。
      - J03 发送换到其他位置→前台规则跟随动作。
      - J04 图案绑定技能→插入正确 mention。
      - J05 保存失败／冲突→重载后的执行与确认状态一致。
      - 上述先在 L1＋L3＋L2／L4 组合验证；真实 Micro 进程首选 J01、J03、J05，技能链变更时补 J04，不把全部组合升为 E2E。
      - 证据边界：注明实际 Micro 入口与重启、隔离或真实 Codex、结果观察点；离屏组合不标 L5，隔离 E2E 不证明真实 Codex 全链。
    - MC-10.6 L6 专项：实机、性能与发布证据
      - Windows 焦点、键盘／输入法、多屏 DPI、文字缩放、高对比度、减少动态效果和实际 Codex 版本兼容。
      - 性能使用同数据集与环境的冷／热耗时、调用数、读写量、内存；反复编辑／取消／重连核对任务与句柄释放。
      - 对绑定优先级、目标保护、保存恢复做风险驱动的变异抽样；数据与权限、运行稳定性按改动风险补充。
      - 发行绑定本次包和摘要；构建、产物运行、安装升级和商店认证分别验收。当前待实施／待运行，不借旧包结果。
      - 需要真实 UI 的操作按明确授权执行；使用专用目标，记录前后状态。设计本身不发起实机测试。
    - MC-10.10 架构与静态检查
      - 依赖方向、公共接口、本地化资源、编译与适用静态分析单独记录，不替代运行行为证据。
      - 分层不要求七套框架；继续使用现有 tests 项目与 scripts/test.ps1，不另建 private 测试仓。
    - MC-10.5 共用异常矩阵
      - 目标：T1 已有会话、T2 确认草稿、T3 未知、T4 导航中、T5 后台、T6 等待中变更。
      - 时序：单次、连击、排队、取消、断开、关闭、迟到结果。
      - 存储：正常、不可写、部分保存、外部修改、损坏、重启。
      - 平台：语言、DPI、焦点、无障碍、减少动态效果。
      - 先保留真实缺陷的固定条件与事件顺序；普通有效组合 pairwise，高风险关联定向三因素或更高阶。
      - 明确合并／拆分等有效性约束；配置组合与事件时序分别覆盖，不支持操作仍保留拒绝场景。
      - 时序用受控任务／时钟／事件，释放前后均断言。只轮询只读结果，不重复操作、不固定睡眠等就绪。
    - MC-10.11 风险优先级与执行时机
      - P0：主线可更换、保存不丢、目标准确、不重复发送／审批；P1：重要分支与恢复；P2：损失有限的低频组合。
      - 按用户损失定级；语言、可访问性或低频问题影响主线与不可恢复结果时提升优先级。
      - 实现时先跑缺陷种子与受影响层；合并前跑必要现有回归、编译和静态检查；发行核对固定输入、代表旅程与实际包。
      - 覆盖率只找遗漏，不设照搬的百分比门禁。局部通过、重试通过和未运行必需项分别记录。
